# ADR Notes

WayAura uses Architecture Decision Records for durable project decisions that should not be repeatedly rediscovered in chat.

Recommended first ADRs:
- Search role is replaceable.
- Documents are the project memory layer.
- Context repo and core repo are separated by responsibility.
- Audio/runtime-sensitive areas are red zones by default.

ADR format should include:
- title;
- status;
- date;
- context;
- options considered;
- decision;
- consequences.
