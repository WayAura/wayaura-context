# DOCINDEX

Compact index of the documents in `wayaura-context`. This is a
quick map, not a substitute for reading the documents themselves.
For the mandatory reading order, follow
[`START_HERE.md`](START_HERE.md). For deciding which repository a
task belongs to, see [`REPO_MAP.md`](REPO_MAP.md).

## Entry path (read in this order)

1. [`START_HERE.md`](START_HERE.md) — mandatory first read; rules
   of entry, what to read next, what not to do.
2. [`AGENT_BRIEF.md`](AGENT_BRIEF.md) — what WayAura is, roles,
   red zones.
3. [`CURRENT_STATE.md`](CURRENT_STATE.md) — current phase, what is
   true right now, what is pending device validation.
4. [`NEXT_WORK.md`](NEXT_WORK.md) — bounded next step; replaced as
   the front of work moves. Not a roadmap.
5. [`REPO_MAP.md`](REPO_MAP.md) — which repository
   (`wayaura-context` vs `wayaura-core`) a given task belongs to.
