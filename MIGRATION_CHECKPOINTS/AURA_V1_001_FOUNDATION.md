# Aura v1 — checkpoint 001: фундамент на Raspberry Pi и панель управления

## Статус

Начат новый цикл разработки — **Aura v1** — на базе сохранённого голосового агента Yandex AI Studio
(Realtime API). Legacy Aura 0.1 и New Aura остаются историей и опытом проекта; их код и документы
не изменялись. Код Aura v1 — в `wayaura-core`, папка `aura-v1/`, ветка
`feature/aura-v1-m0-realtime-roundtrip`; в `main` не влит.

Legacy Aura 0.1 по-прежнему штатно работает на стендовом Raspberry Pi (`aura.service` включён).
Aura v1 запускается только на время сеанса панели управления и возвращает Legacy при остановке.
Автозапуска Aura v1 нет — по решению владельца.

## Что подтверждено фактами

- **Milestone 0 (ноутбук).** Факты по Realtime API: агент подключается по ID через
  `session.update → prompt.id`; PCM16 моно на 16/24/44,1 кГц работает, 48 кГц — нет; серверный VAD
  стабилен, ручной режим ненадёжен; `input_audio_buffer.clear` не поддерживается и рвёт сессию;
  `response.cancel` действует только до прихода звука. Подробно — `aura-v1/FINDINGS.md` в `wayaura-core`.
- **Сервис на Pi.** Голосовой контур через агента с серверным VAD; USB-микрофон AB13X (48 кГц) и HDMI
  на телевизор с пересчётом частот; полудуплекс; сон после 2 минут тишины; переподключение
  (сработало вживую на Pi); канал управления WebSocket + JSON с токеном.
- **Панель на ноутбуке** (`aura`): проверки, запуск/остановка v1, живая лента, вопрос текстом,
  остановка ответа. Возврат Legacy после выхода проверен на железе (≈ 1 с до `active`).
- **Автопроверки на Pi без человека:** голосовая реплика тестовой фразой — звук ответа через
  0,34 с после конца фразы по VAD (+0,8 с паузы VAD); текстовый вопрос; остановка ответа; реальный
  микрофон открывается и отдаёт звук. Живой голосовой тест владельцем — ещё не проведён.

## Сохранено перед работой

- Бэкап стендового Pi (Legacy-каталог, юнит, git-клон New Aura) — вне репозиториев, у владельца.
- Незапушенная работа New Aura с Pi сохранена на GitHub: `feature/continuous-realtime-runner`
  (как есть) и `backup/pi-state-20260923` (незакоммиченные правки и локальная правка
  `audio_detect.sh`). Сам Pi при этом не менялся.

## Целевая картина (не реализовано)

Pi — мозг и голос Ауры в защищённом корпусе в машине, питание от аккумулятора, звук в колонки авто.
Собственный OBD2-диагностер по Bluetooth подключается к Pi и телефону. Телефон с приложением —
главный пульт и основной микрофон; микрофоны в салоне — запасной вариант. Аура озвучивает данные
авто по команде. SSH и ноутбук — только канал разработки.
