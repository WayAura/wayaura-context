# Aura v1 — checkpoint 005: версия aura-v1.0, голос с телефона, проект связки

## Статус

2026-09-26. Метка `aura-v1.0` в `wayaura-core` на `main` 7b199da (этап 2 и этап 3; только этап 2 — c463061),
Pi на этой версии. Слово «Аура» на Pi из `main` откачено (PR #7) и живёт в `feature/aura-v1-wake-word`.

## Что сделано

- **Голос с телефона — основной вход** (сейчас телефон имитирует панель на ноутбуке): голос двоичными
  сообщениями по каналу управления, PCM16 16 кГц по 20 мс; вход `pi | remote` переключается без остановки
  Ауры; при обрывах Аура слышит тишину и не зависает; `listen` с `source: phone_wake` — слово услышал телефон.
  Ответ ≈ 1,1–1,3 с после конца фразы — как с микрофоном Pi.
- **Проект связки «Аура + телефон + OBD2»** для команд приложения и диагностера —
  `wayaura-core/aura-v1/docs/PHONE_LINK.md`; сценарий в машине и целевая архитектура — решения владельца (§9).
- **Проверки на Pi:** окно уточнения, время, заглушка OBD2, приветствие (только на «кто ты»), выход из
  панели — в порядке; вызов функции текстом не повторился (16 из 16 после замены приветствия); откат к
  метке проверен безопасно, инструкция исправлена.
- **Петля через телевизор:** гонка HDMI при загрузке закрыта; дважды телевизор молчал при играющем выводе —
  сторона телевизора, не установлено (FINDINGS.md).
