# Aura v1 — checkpoint 002: одна Аура, связь стенда, модель агента

## Статус

2026-09-25. На стендовом Raspberry Pi работает только Aura v1 и только с агентом владельца;
Legacy Aura остановлена и отключена. Живой голосовой тест владельцем — впереди.

## Решения владельца

- Правило «одна Аура, без подмен»: никаких автоматических переключений на другие ассистенты, модели
  или версии; если с Aura v1 что-то не так — её чинят. Legacy — только ручной аварийной командой.
- Модель агента — `speech-realtime-260528` (как настроено в AI Studio), одна, без запасных.
- Энергосбережение Wi-Fi на Pi выключено навсегда.
- Направление по активации принято: «слушаю по нажатию» + окно уточнения 6–8 с по умолчанию,
  слово «Аура» на Pi вторым режимом; реализация — отдельным этапом после живого теста.

## Подтверждено на железе

- Пропадания Pi — энергосбережение Wi-Fi на Pi (модуль спал и не отвечал даже на ARP); после
  выключения и перезагрузки Pi настройка сохраняется, связь поднимается сама.
- Панель находит Pi после смены адресов раздачи (опознание по ключу SSH) и переподключается после
  обрыва (≈ 3 с), Aura v1 при этом не прерывается.
- «Отвечает агент владельца» (модель 260528, отпечаток инструкций, без ID); неизвестный ID агента —
  понятная ошибка и остановка, без подмены.
- Выход из панели останавливает только Aura v1; после перезагрузки Pi Legacy не запускается.
- Полный синтетический прогон на Pi: голос, текстовый вопрос, остановка ответа.
- Сравнение моделей на Pi: 260528 отвечает на ≈ 0,25–0,4 с позже 250923 и чуть короче.
